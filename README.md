# OpiArto — privacy policy

The privacy policy for the OpiArto study planner, published at
**https://auroracamsolutions.github.io/opiarto-privacy/**

That URL is what the Google Play listing points at, and Play requires it to
stay reachable for as long as the app is published. This repository is public
and holds nothing but the page: no app source, no keys.

The policy's central claim — that nothing leaves the device — is checkable
against the app itself: there is no `INTERNET` permission in its manifest and
no networking code in it. If that ever changes, this page changes first.

Edit `index.html`, commit, and GitHub Pages republishes it.
